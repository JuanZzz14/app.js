# Flowk

Aplicativo mobile de produtividade para combater a procrastinação, desenvolvido em React Native com Expo.

---

## Sobre o Projeto

O Flowk foi criado para ajudar estudantes e profissionais a organizar suas tarefas diárias de forma simples e objetiva. Com uma interface limpa e navegação intuitiva, o objetivo é criar o hábito de planejar o dia e acompanhar o próprio progresso.

## Telas

| # | Tela | Descrição |
|---|------|-----------|
| 1 | Home | Tela inicial com cards de acesso rápido |
| 2 | Lista | Lista de tarefas com marcação de status |
| 3 | Formulário | Cadastro de meta com nome e e-mail |
| 4 | Configurações | Preferências do app (notificações, modo escuro, sons) |
| 5 | Sobre | Informações sobre o projeto |

## Tecnologias

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [Expo Snack](https://snack.expo.dev/)

## Como Executar

### Opção 1 — Expo Snack (recomendado)

1. Acesse o link do projeto no Expo Snack:  
   [snack.expo.dev/@juanzzz/app-mobile](https://snack.expo.dev/@juanzzz/app-mobile?platform=web)
2. Abra o app **Expo Go** no seu celular
3. Escaneie o QR Code exibido na página
4. O app será carregado automaticamente

### Opção 2 — Rodar localmente

**Pré-requisitos:**
- Node.js v18+
- Expo CLI: `npm install -g expo-cli`
- App Expo Go instalado no celular

**Passos:**

```bash
git clone https://github.com/JuanZzz14/app.js.git
cd app.js
npm install
npx expo start
```

Escaneie o QR Code gerado com o Expo Go.
